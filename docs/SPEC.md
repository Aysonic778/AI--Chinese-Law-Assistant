# 法律资料库可信问答 — 工程规格书（CEO Review 修订版）

## 1. 产品目标

构建一个 NotebookLM 风格的中国法律资料库问答 Web 应用，核心承诺是 **「引用或拒答」**：只从资料库检索到的原文作答，禁止联网与幻觉。

## 2. 目标用户

法律专业人士及有法律研究需求的个人用户（MVP）。

## 3. MVP 范围

### 包含

- 脚本导入 5 部预置法典
- 法律条文智能分块（按「第 X 条」）
- ChromaDB 向量检索（单阶段）
- Chat 单轮问答（SSE）
- 强制法条引用 + 软拒答
- 免责声明固定展示

### 不包含（Phase 2）

- 资料库管理 Web UI
- 两阶段 Law Router
- Reranker 精排
- 多轮对话 / 历史
- Docker Compose
- 用户认证

## 4. 核心流程

1. `scripts/import_laws.py` 导入 `data/laws/*.txt`
2. 用户提问 → 向量检索 Top-K
3. 相似度 < 阈值 → 软拒答 + 最接近条文摘录
4. 相似度达标 → LLM 基于检索原文生成 + 引用标注

## 5. 防幻觉策略（MVP）

| 层级 | 机制 |
|---|---|
| 检索门槛 | `MIN_RELEVANCE_SCORE` 不达标则软拒答 |
| Prompt | 禁止外部知识，temperature 0.05 |
| 引用 | 回答展示可点击法条引用卡片 |
| 软拒答 | 附最接近 3 条摘录，标注不足以得出结论 |

## 6. 成功指标

- 法条引用准确率 ≥ 90%（人工抽检 20 题）
- 无编造法条编号
- 无覆盖问题 100% 软拒答
- 流式首 token < 3 秒

## 7. 技术架构

```
frontend (Next.js) → backend (FastAPI) → ChromaDB + SQLite
                                      → LLM API (Qwen/DeepSeek-V3)
```

## 8. 合规

- 固定免责声明
- 显示法律版本日期
- 明确资料库覆盖范围局限
